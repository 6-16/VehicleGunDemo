ProBase

Dependency injection, an application state machine, a UI framework and a wired scene setup for Unity.

Overview

ProBase is a running application. After import, four scenes are wired together, the container is configured, and the UI system is operational. Replace the contents of the Gameplay scene with your own content and keep the rest.

All types are in the ProBase namespace.

PartDescription
ZenjectDependency injection, bundled in Assets/Plugins/Zenject
App state machineScene flow, with typed payloads passed into loaded scenes
UI frameworkScreens, layered canvases, transitions, dialogs, safe area, paging
Pause systemScene scoped service driving Time.timeScale, with a pause overlay
ScenesBoot, MainMenu, Loading, Gameplay
Editor toolsBuild settings assignment, TextMeshPro import, play mode boot routing

Requirements

Unity 6 or newerThe framework uses UnityEngine.Awaitable
Input System packageActive Input Handling set to Input System Package or Both
TextMeshPro essentialsImported from the ProBase menu

No render pipeline is required. The package references no pipeline assets, materials, physics, sprites or meshes, and behaves identically in Built-in, URP and HDRP, in 2D and 3D, on all build targets.

Installation

  1. Import the package.
  2. The Project Setup window opens once, on first import.
  3. Press Assign Scenes. The build settings scene list is replaced with Boot, Loading, MainMenu and Gameplay, in that order.
  4. Press Import TextMeshPro Essentials if reported as missing.
  5. Press Play.

Both actions are also available from the ProBase menu. Nothing runs automatically after the first window.

Startup sequence

Boot scene
  SceneContext        creates ProjectContext
  ProjectInstaller    binds services and app states
  AppBootstrapper     enters MainMenuState

MainMenuState
  SceneTransitionService loads Loading, then MainMenu
  UIInstaller         creates UIRoot, opens the entry screen

Play pressed
  EnterAsync<GameplayState, GameplayRequest>(request)
  Loading, then Gameplay with the request bound into its container

The Boot scene contains a camera and an empty SceneContext. The SceneContext triggers creation of the ProjectContext.

In the editor, play mode starts from the Boot scene regardless of which scene is open.

App state machine

An app state owns a scene. It is entered, loads its scene, and is exited when another state is entered. States are resolved by type and bound in ProjectInstaller.

InterfaceSignature
ISimpleAppStateAwaitable EnterAsync()
IPayloadAppState<TPayload>Awaitable EnterAsync(TPayload payload)
await _stateMachine.EnterAsync<MainMenuState>();
await _stateMachine.EnterAsync<GameplayState, GameplayRequest>(request);

bool inGame = _stateMachine.IsIn<GameplayState>();

Calls made while a transition is running are ignored. IsTransitioning reports the current state.

Adding a state

1. Implement the state.

public class SettingsState : ISimpleAppState
{
    private readonly SceneTransitionService _sceneTransition;
    private readonly SceneCatalog _sceneCatalog;

    public SettingsState(SceneTransitionService sceneTransition, SceneCatalog sceneCatalog)
    {
        _sceneTransition = sceneTransition ?? throw new ArgumentNullException(nameof(sceneTransition));
        _sceneCatalog = sceneCatalog != null ? sceneCatalog : throw new ArgumentNullException(nameof(sceneCatalog));
    }

    public Awaitable EnterAsync()
    {
        return _sceneTransition.LoadAsync(_sceneCatalog.Settings);
    }

    public Awaitable ExitAsync()
    {
        return Awaitable.NextFrameAsync();
    }
}

2. Bind it in ProjectInstaller.InstallAppStates.

Container.Bind<IAppState>().To<SettingsState>().AsSingle();

3. Register the scene. Add a SceneReference field to SceneCatalog, assign the scene asset, then run ProBase > Assign Scenes.

4. Enter it.

await _stateMachine.EnterAsync<SettingsState>();

Scene payloads

A payload state binds its payload into the container of the scene it loads. The receiving scene resolves it by injection.

public Awaitable EnterAsync(GameplayRequest payload)
{
    if (payload == null) throw new ArgumentNullException(nameof(payload));

    return _sceneTransition.LoadAsync(
        _sceneCatalog.Gameplay,
        container => container.Bind<GameplayRequest>().FromInstance(payload).AsSingle());
}
[Inject]
private void Construct(GameplayRequest request)
{
    _request = request ?? throw new ArgumentNullException(nameof(request));
}

GameplayRequest ships empty. Add fields to it, or replace it with your own type and update GameplayState.

Loading progress

LoadingProgress is project scoped. SceneTransitionService writes to it during a load; LoadingScreen reads it.

_progress.Changed += OnProgressChanged;

private void OnProgressChanged()
{
    _progressFill.fillAmount = _progress.Value;
}

Value is clamped to 0 to 1. Changed fires only when the value changes.

UI framework types

TypeRole
UIScreenA screen. A prefab with a CanvasGroup and this component or a subclass.
UIScreenDefinitionScriptableObject describing one screen: prefab, layer, behaviour.
UISceneConfigThe definitions a scene uses, and its entry screen.
IUIServiceThe runtime API.
UIRootViewThe canvas hierarchy, created per scene from the UIRoot prefab.

A screen's identity is its component type. ShowAsync<PauseScreen>() resolves the definition whose prefab carries a PauseScreen component.

Screens are instantiated on first use and cached. Enable Destroy On Close on a definition to release the instance on close instead.

Adding a screen

1. Implement the screen.

public class SettingsScreen : UIScreen
{
    [SerializeField] private Button _closeButton;

    private IUIService _uiService;

    [Inject]
    private void Construct(IUIService uiService)
    {
        _uiService = uiService ?? throw new ArgumentNullException(nameof(uiService));
    }

    protected override void OnOpened()
    {
        _closeButton.onClick.AddListener(OnCloseClicked);
    }

    protected override void OnClosing()
    {
        _closeButton.onClick.RemoveListener(OnCloseClicked);
    }

    private async void OnCloseClicked()
    {
        await _uiService.CloseAsync<SettingsScreen>();
    }
}

2. Build the prefab. Stretched RectTransform on the root, a CanvasGroup, and the script. Assign the CanvasGroup to the Canvas Group field. Optionally add FadeScreenTransition and assign it to Transition; leaving it empty opens the screen without animation.

3. Create the definition. Create > UI > Screen Definition, assign the prefab, select the layer.

4. Register it in the UISceneConfig of each scene that shows it.

5. Show it.

await _uiService.ShowAsync<SettingsScreen>();

Lifecycle

HookCalled
OnOpeningObject active, before the show transition
OnOpenedAfter the show transition, screen interactive
OnClosingBefore the hide transition
OnClosedAfter the hide transition, object inactive

Interaction is disabled for the duration of both transitions.

Arguments

Derive from UIScreenWithArgs<TArgs>. Arguments arrive before the screen opens, in OnArgsReceived, and are available through Args.

public class MessageScreen : UIScreenWithArgs<string>
{
    [SerializeField] private TMP_Text _label;

    protected override void OnArgsReceived()
    {
        _label.text = Args;
    }
}

await _uiService.ShowAsync<MessageScreen, string>("Saved");

Results

Derive from UIScreenWithResult<TArgs, TResult> and call SetResult. The caller awaits the value.

public class ConfirmScreen : UIScreenWithResult<ConfirmArgs, bool>
{
    private void OnConfirmClicked() => SetResult(true);
    private void OnDeclineClicked() => SetResult(false);
}
bool confirmed = await _uiService.ShowForResultAsync<ConfirmScreen, ConfirmArgs, bool>(
    new ConfirmArgs("Quit to the main menu?"));

if (confirmed)
{
    await _stateMachine.EnterAsync<MainMenuState>();
}

The service closes the screen once the result is set. If the screen is closed by any other route, the awaiting call receives default.

Layers

The UIRoot prefab holds three stacked canvases. A definition assigns its screen to one of them.

LayerSort orderBehaviour
UILayer.Screen0Opening one closes all other Screen layer screens
UILayer.Hud100Independent of Screen and Overlay layers
UILayer.Overlay200Stacks freely above the other layers

Within a layer, Sort Priority sets draw order; higher values draw above lower ones.

Each layer is a separate canvas, so a change in one does not rebuild the geometry of the others.

Transitions

A transition is a component on the screen prefab, assigned to the screen's Transition field.

FadeScreenTransitionAlpha fade with configurable duration
InstantScreenTransitionImmediate

Custom transitions derive from ScreenTransition.

public class SlideScreenTransition : ScreenTransition
{
    public override Awaitable PlayShowAsync(CanvasGroup canvasGroup) { ... }
    public override Awaitable PlayHideAsync(CanvasGroup canvasGroup) { ... }
}

The bundled transitions advance on Time.unscaledDeltaTime, so they run while timeScale is zero.

Navigation

MethodEffect
BackAsync()Closes the topmost Overlay layer screen. Screen layer screens are unaffected.
CloseAsync<T>()Closes a specific open screen
CloseTopAsync()Closes the top of the stack
CloseAllAsync()Closes every open screen
IsOpen<T>()Whether that screen is in the stack
Get<T>()The cached instance, or null

Enable Blocks Back on a definition to make a screen ignore the cancel input.

The cancel input is bound through the Cancel Action field on UIInstaller and GameplayInstaller. Each binds its own listener, so assign the action on only one installer per scene. In the Gameplay scene it is assigned on GameplayInstaller.

Input is blocked for the duration of every open and close.

Safe area and scaling

SafeAreaFitter insets the RectTransform it is attached to so that it matches Screen.safeArea. It drives the anchors of that object every frame, so the object should not be anchored manually.

Place it on a content child. Objects outside it, such as backgrounds and dimmers, fill the whole screen.

MyScreen           stretched, CanvasGroup, screen script
├── Background      stretched, fills the screen
└── Content         SafeAreaFitter, holds buttons and text

CanvasScalerPolicy configures the CanvasScaler to scale with screen size against a reference resolution, and selects the match axis from the display aspect ratio relative to that reference.

Pause

PauseService is bound per scene in GameplayInstaller. It holds the paused state, sets Time.timeScale, and fires PauseChangedSignal.

_pauseService.Pause();
_pauseService.Resume();

bool paused = _pauseService.IsPaused;

PauseScreen calls Pause in OnOpening and Resume in OnClosed. PauseService.Dispose restores timeScale when the scene container is destroyed.

_signalBus.Subscribe<PauseChangedSignal>(OnPauseChanged);
